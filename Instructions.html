Quick Setup & Launch

Getting started with Vertex on your computer
Portable & Fast
  • Keep Application Files Together
    Ensure that Vertex.exe and the Main/ folder remain in the exact same directory. Do not separate or move them into different folders.
  • Launch Vertex
    Simply double-click Vertex.exe to start the application. Vertex is fully portable—no complex installation wizard or background services required.
  • Install Tools on Demand
    Vertex ships with a clean, lightweight baseline. Navigate to Settings → Module Manager and switch to the Cloud Store to install the exact tools you need in one click.
🧩

Module Manager & Cloud Store

Manage installed tools, cloud updates, and local packages
Extensible

📥 1-Click Cloud Store

Switch to the "Cloud Store" tab in Module Manager to browse official tools and install them directly in one click.

🔍 Catalog Filters & Search

Filter addons by Category and Author, sort by name or release date, and search through full descriptions in real time.

📖 In-App Documentation

Click any module card in the catalog to view its full documentation, feature set, and usage guide before installing.

📦 Local .vtx Installation

Install offline .vtx packages by clicking "Install Local File" and picking the package from your computer.

⚡ Smart Update Alerts

When a newer version of an installed module is released, an "⚡ Update Addon" button appears automatically.

🗑️ Clean Uninstall

Uninstall tools you no longer need with a single click. Removed packages leave zero orphan files behind.

App Customization & Real-Time Logs

Personalize your visual experience and monitor app operations
Personalization

🎨 Curated Color Palettes

Head to Settings to choose from 7 curated color palettes (Monochrome Black, Teal & Cyan, Royal Purple, Emerald Green, and more).

☀️ Light & Dark Appearance

Toggle seamlessly between Dark Mode and Light Mode with high-contrast text and border rendering across all views.

📜 Live Activity Log Window

Click "Open Logs" in Settings to open an instant PowerShell terminal streaming real-time activity and diagnostics.

Security & Data Privacy

Your data belongs entirely to you
Privacy First

Vertex does not collect, track, or retain any personal data or files. The software is designed to operate completely offline, except for features that inherently require network access (such as Cloud Store downloads or GSTR Portal retrieval).

🛡️ 100% Local Processing

Document parsing, spreadsheet consolidation, and local OCR execute entirely on your machine with zero data sent over the network.

🚫 Zero Analytics & Telemetry

Vertex contains zero usage tracking, zero analytics beacons, zero call-home pings, and zero third-party telemetry scripts.

📁 Portable Local Storage

All configuration settings and installed plugins are stored strictly within the application folder (inside UserData/).
